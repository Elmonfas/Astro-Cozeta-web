# Variantes del logotipo

Estas variantes **no se publican en la web**: solo se usan tres logos en el sitio y el resto se
servía sin que nadie las pidiera, sumando peso a producción y quedando accesibles por URL.

Se conservan aquí para papelería, redes sociales y materiales impresos.

Las que sí usa el sitio están en `public/logos/`:

| Fichero | Dónde |
|---|---|
| `cozeta-logo-horizontal.svg` | Cabecera (fondo claro) |
| `cozeta-logo-horizontal-negativo-transparent.svg` | Pie (fondo oscuro) |
| `cozeta-isotipo.svg` | Póster del logo 3D del hero, y origen de los favicon |
